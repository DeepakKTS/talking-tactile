# Demo readiness

1. Fresh clone, `make dev` from scratch. It must start with no manual steps beyond `.env`.
2. Mock mode run of the whole script with the network off. Everything except questions must work.
3. Live run of the whole script twice in a row with no restart.
4. Lighting: overhead light on, no window glare on the sheet.
5. Phone stand fixed, sheet taped at two corners, recalibration done.
6. Credits left noted. Cost meter reset.
7. `eval/RESULTS.md` is from today. Numbers in the script match it.
8. Audio levels: app voice audible over the narration track.
9. If any step fails, fix it or cut it from the script. Never record a step that only works sometimes.
